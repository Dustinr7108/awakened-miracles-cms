Here’s a step-by-step breakdown of a comprehensive video editing workflow. This guide covers everything from initial project setup and media organization to final export and feedback handling, with tips specific to Premiere Pro, Final Cut Pro, and DaVinci Resolve. Each section is organized clearly, and key differences between NLEs are noted for tools like proxy generation, color grading, and graphics.

1. Project Setup
Disk Folder Structure: Organize your project on disk with a clear folder hierarchy. A recommended structure might look like this:

01_PROJECT (holds the project file and autosaves)
02_MEDIA (contains raw media)
   CAM_A (clips from Camera A)
   CAM_B (clips from Camera B)
   SCREENRECS (screencaptures or web clips)
   AUDIO (recorded audio tracks)
   MUSIC (licensed or royalty-free music tracks)
   SFX (sound effects)
   GRAPHICS (static images, graphics, etc.)
03_PROXIES (place to store proxy media)
04_EXPORTS
   REVIEW (exports for client review or rough cuts)
   FINAL (final exports for delivery)
99_ASSETS (miscellaneous assets like LUTs, templates, etc.)
This structure keeps media, proxies, and project files organized. It’s easy to find where things live and keeps backups and client reviews separate.

Naming Convention: Use a consistent naming convention for project files and assets. For example:

Project file: PROJECTNAME_YYYY-MM-DD_v01.prproj (where YYYY-MM-DD is the date and v01 is the version number). In Final Cut, this would be PROJECTNAME.fcpbundle (or a single .fcpxml file), and in DaVinci Resolve, it’s PROJECTNAME.drp. Increment versions with meaningful labels (e.g. v02, v03-feedback, v04-lock) when you make real changes.
Media files: Rename clips to something human-readable when you import them. For instance, A001_opening-wide.mov instead of a cryptic C0001.MP4. This makes it easier to reference clips by name later. Keep proxies with the same name as the original clips so you can easily relink them if you move drives.
Sequence Settings: Set up your timeline sequence in the editing software with the appropriate resolution and frame rate. Always edit in the final destination format if possible. For example, if your final video will be 1080p at 29.97 fps, make the timeline that resolution and frame rate. If you have 4K footage, you can either import it at full resolution and scale it down to 50% (so it plays at 1080p on your timeline) or use proxy media as described in the next section. If you need different aspect ratios for social media (like 16:9 for YouTube vs 9:16 for Instagram), create separate sequences for each format during initial setup. This way you can easily switch to the correct sequence for different export settings later.

2. Asset Organization Inside NLE
Within the editing software, organize your media into bins (folders) and apply labels for clarity. A common set of bins for video editors is:

01 Sequences: Contains your timeline sequences (the finished video edit). You might also keep “Drafts” or “Rough Cuts” sequences here as separate versions.
02 Video – A Cam: Holds video clips from Camera A.
03 Video – B Cam: Holds video clips from Camera B.
04 Audio – Lav/VO: Holds any audio from lavalier mics or voiceover recordings.
05 Music: Holds all music tracks used in the project.
06 SFX: Holds all sound effects.
07 GFX / Titles: Holds graphics, overlays, and title templates.
08 Color / LUTs: Holds any color presets or LUTs (look-up tables) you use for grading.
Applying color labels to clips can make your timeline easier to read at a glance. For example:

Label Dialogue audio or video clips in one color (say red) so you can quickly identify talking head footage.
Label B-roll clips in another color (say blue) for supporting video shots.
Label Graphics or title clips in a third color (say green) for overlays or text.
This labeling system helps you scan the timeline and know at a glance what each clip is. Some NLEs allow you to mark clips or use metadata tags as well. In Premiere Pro, you can set labels in the Project panel; in Final Cut, you can use color-coded tags or keywords; in DaVinci Resolve, you can use color labels on media in the Media Pool.

Metadata Tips: Take advantage of the metadata capabilities in your software. In Premiere, you can add descriptive notes to clips or sequences in the Info panel. In Final Cut, use the Keywords field in the Inspector. In DaVinci Resolve, you can add tags to media clips. This can be useful for organizing large projects or for sharing project files with collaborators. For example, you might tag a clip with “Interview” or “Outdoor” to easily find it later. Good metadata management will save you time when searching for specific shots or when you need to hand off the project to someone else.

3. Proxy Workflow for 4K
When working with high-resolution footage (like 4K or 6K video), it’s often easier to use proxy files during editing to improve performance. Proxies are lower-resolution versions of your media that you edit with, then relink to the original high-res files when you export. Here’s how to set up proxies in each NLE:

Premiere Pro: Right-click on the clip or on a folder of clips in the Project panel and choose Proxy > Create Proxies. Select a proxy format (e.g. ProRes Proxy or Cineform Low) and choose a destination folder (like your 03_PROXIES folder). Premiere will generate proxies with the same name as the originals. Later, if you need to export the full resolution, you can use Proxy > Relink All to switch back to the high-res files. Make sure proxies are in the same folder as the original media or adjust the media cache paths so Premiere can find them. Keep your proxy files organized in a dedicated folder (like 03_PROXIES) so you can easily delete them or archive them after the project is done.
Final Cut Pro: Use the Transcode function to create proxies. In the Log & Transfer window, select your media clips. Click the gear icon and choose Create Proxy Media. You can choose a format (ProRes Proxy or H.264 Proxy) and a destination folder. FCP will create the proxies and automatically relink to them when you import the media. If you later want to switch to the original media, go to the Modify menu and choose Use Original Media. Final Cut will prompt you to locate the original files. Proxies in FCP are stored in the Media folder within your project bundle by default, but you can specify a different location. It’s good practice to keep proxies in a separate folder for clarity (and to keep them out of your original media folder).
DaVinci Resolve: DaVinci Resolve has two ways to handle proxies: Optimized Media and Proxy Media. Optimized Media are lower-resolution copies of your media that Resolve generates on import. To generate them, go to the Media Pool, select your media, and click the Generate Optimized Media button. By default, Resolve will create Optimized Media at 1080p if you’re editing in 1080p. Proxy Media are even lower-resolution versions (for example, 720p or 480p) that you can use for playback. You can generate Proxy Media by right-clicking on your media in the Media Pool and choosing Generate Proxy Media. Resolve will ask for a destination folder (like 03_PROXIES). Once proxies are generated, Resolve will use them by default for editing – you’ll see a small proxy icon on the clip in the timeline. When you export, Resolve will automatically use the original media. To switch back, you can use the Proxy button in the Media Pool (or in the Playback tab) to toggle between Original and Proxy. DaVinci Resolve also allows you to set up a Proxy Generator in the Project Settings so that it automatically creates proxies for new media you import. This is a convenient way to ensure all new footage gets proxied without manual intervention.
Key Points: Whether you use ProRes, H.264, or Cineform proxies, the goal is to have a version of your media that your computer can handle smoothly while you edit. After you’re done editing, you can export with the original high-res media by relinking or using the appropriate export settings. Keeping proxies in a separate folder and using the same naming as the original clips makes it easy to swap back and forth. Some editors prefer to keep the proxies alongside the original media but in a different subfolder (e.g. CAM_A/proxies), which also works. Just make sure that if you move your project or media, the proxy paths stay valid. By using proxies, you avoid bogging down your system with heavy 4K footage and can work faster and more efficiently.

4. Assembly Edit (Rough Cut)
The assembly edit is the process of putting the footage together in the order of the story, without worrying too much about perfection. It’s like building a rough cut or a “first pass” of the video. Here’s how to approach it:

Import Footage and Organize in Timeline: Import all your raw footage (video, audio, graphics) into your project and organize them in the appropriate bins. Then, create a new sequence in your editing software (or use the one you set up in project setup) and start adding clips to it in the order you want them to appear in the final video. The idea is to drop selects – meaning, import all the footage you think might be useful and then drag the parts you need into the timeline in the right sequence. Don’t get bogged down by perfect cuts or transitions at this stage. The goal is to get the story down and see how all the pieces fit together. This is a fast, no-frills edit – it’s okay if it’s rough. You can even do this on a proxy timeline if you have 4K footage.
Focus on Story Beats: When assembling the timeline, think in terms of story beats and structure. Start with a hook – something that grabs the viewer’s attention immediately. Then provide context – give the viewer some background or setup. Next, establish the value proposition – tell the viewer what they’ll get out of watching. Finally, include a call-to-action (CTA) – prompt the viewer to do something, like subscribe or visit a link. By focusing on these key story points, you ensure the rough cut has a clear flow. If you’re working with a script or outline, follow that; if not, use the footage to guide you. Try to maintain the rhythm of the footage: if it’s an interview, cut between the interviewer and interviewee in a logical way. If it’s a montage, keep the pace up. Remember, you can always refine the order later. The assembly is about getting the sequence right, not the style.
Use Markers for Sections: As you assemble the timeline, use markers to indicate sections or scene breaks. In Premiere Pro, you can use the M key to place markers on the timeline. In Final Cut, use the Command+M shortcut. In DaVinci Resolve, use the M key or right-click on the timeline to add markers. Label each marker with a brief description (e.g. “Scene 1 – Hook”, “Scene 2 – Context”, “Scene 3 – Value”, “Scene 4 – CTA”). This will help you and others quickly navigate the timeline later, especially when reviewing or making changes. Markers are also useful for adding notes or timecodes. For example, if you have a long sequence and want to flag a specific part for later, a marker can be a reminder. Using markers at this stage makes the feedback process easier too, as discussed in the next section.
Fast Editing Moves: To speed up the assembly edit, use the following keyboard shortcuts (many of these are similar across NLEs, though the keybindings might differ slightly):
Insert Edit: In Premiere, press , (comma) to insert a clip at the playhead position without overwriting. In Final Cut, you can use the insert edit tool (or press B to enter the insert tool). In DaVinci Resolve Cut page, you can use the Insert tool (or Shift+I). Insert edits add clips without removing existing content, which is useful for building a sequence without cutting out existing material accidentally.
Overwrite Edit: In Premiere, press . (period) to overwrite existing content at the playhead. In Final Cut, use the overwrite tool (or press O). In DaVinci Resolve Cut page, use the Overwrite tool (or Shift+O). Overwrite edits replace whatever is at the playhead with the selected clip. Use these when you’re ready to cut out the old material and replace it with the new.
Ripple Trim: In Premiere, use Q to trim the start of a clip and W to trim the end of a clip. In Final Cut, use the ripple trim tool (or press Shift+] to trim the end or Shift+[ to trim the start). In DaVinci Resolve Cut page, you can use the Ripple trim tool (or press Shift+T). Ripple trims adjust a clip’s length and automatically adjust the surrounding edits (rippling the timeline) so that nothing is left hanging. This is great for fine-tuning the length of a clip without affecting the flow of the rest of the edit.
Duplicate Clip: In Premiere, hold Alt (Windows) or Option (Mac) and drag a clip to duplicate it. In Final Cut, hold Option and drag to duplicate. In DaVinci Resolve, hold Alt (Windows) or Option (Mac) and drag to duplicate. Duplicating clips can save time if you need multiple instances of the same clip (for example, if you want to show a clip from two angles back-to-back).
Add Edit: In Premiere, press Ctrl+K (Windows) or Command+K (Mac) to split a clip at the playhead. In Final Cut, press B to split a clip at the playhead. In DaVinci Resolve, press B to split a clip at the playhead. Adding an edit is the basic way to cut a clip into two pieces – use this when you want to remove a section of a clip.
DaVinci Resolve Cut Page: If you’re using DaVinci Resolve’s Cut page, it has some unique tools to speed up the assembly. You can use the Source Tape window to scrub through footage and then use the Smart Insert button to quickly add the selected clip to the timeline. This automatically positions the clip at the playhead and inserts it without overwriting (like an insert edit). You can also use the Smart Overwrite button to replace whatever is at the playhead with the selected clip. These “smart” tools are designed to mimic the behavior of a traditional tape editor, which can be very efficient for quickly putting together a rough cut. The Cut page also allows you to work with multiple camera angles in a timeline (like an A/B edit view) to quickly cut between different takes or angles of the same shot.
Speed Through Footage: Remember, this is the assembly – don’t get caught up in details. Just get the footage in order. If you have long interviews or B-roll, you can trim them later in the fine cut. The key is to build the skeleton of the video. By using the fast editing moves and the tools in each NLE, you can put together a rough cut relatively quickly. Once you have the assembly done, you’ll have a clearer picture of the story and where you might need to add or remove footage in the next step.

5. Fine Cut
After you have the rough cut assembled, it’s time to refine it into a polished edit. The fine cut involves improving pacing, tightening up the edit, and adding finishing touches. Here’s what you’ll do:

Improve Pacing: Watch your rough cut and identify any parts that feel slow or drag on. This could be dead air, long pauses, or overly long shots. Use the ripple trim tool to shorten these segments. If a clip is too long, cut it down to the essential parts. Conversely, if a scene feels too short, see if you can add a bit more footage or transition to extend it. Pay attention to the rhythm of the video – aim for a smooth flow. You might find that removing a few frames here and there (e.g. trimming a beat or a moment) can make the edit feel more energetic. Be careful not to cut out important information or context, though. The goal is to keep the viewer engaged, so if something is necessary for the story, leave it in.
Trim Breaths and Flubs: In talking head footage (interviews, etc.), it’s common to have pauses, breaths, or minor mistakes. Use the fine cut to trim these out. For example, if someone takes a deep breath before speaking, you can cut just before or after that breath to eliminate the dead air. If there’s a double-take or a slight stumble, you might cut around it. Use the J-cut or L-cut techniques to smooth over these transitions, which we’ll cover below. Remember, the audience shouldn’t notice these cuts – they should just feel like a natural flow. Aim for a seamless edit. A good rule of thumb is: if a part of the footage doesn’t add to the story or doesn’t improve the pacing, it should go.
Add J-cuts and L-cuts: These are editing techniques that can make your video feel more professional and polished. A J-cut is when the audio leads the video. For example, you might start with a piece of music or a voiceover before the corresponding video appears. This creates a sense of anticipation. A L-cut is when the video leads the audio – the video starts before the audio does. For instance, you might show someone walking into a room (video) before you hear them speak (audio). Both J-cuts and L-cuts can add a cinematic feel to your video. In the fine cut, identify places where you can apply these. For example, if you have a voiceover narration, you could use a J-cut by starting the voiceover a second or two before the relevant visuals appear. Or if you have a scene change, you could use an L-cut by showing the next scene for a moment before the audio of that scene comes in. To implement a J-cut in Premiere Pro, you would have the audio clip start before the video clip on the timeline. In Final Cut, you can do the same by having the audio track begin before the video track. In DaVinci Resolve, simply place the audio clip before the video clip on the timeline. For an L-cut, do the opposite: place the video clip before the audio clip. These techniques take a bit of practice, but they can really enhance the flow of your video and make it feel more like a high-quality production.
Smooth Camera Mismatches: If you’re editing footage from multiple cameras or angles, you might notice slight mismatches – for example, the scale of a subject or the camera angle changes abruptly between cuts. In the fine cut, use subtle techniques to smooth these out. One method is to scale and position the footage. If the next shot is slightly larger or smaller, you can use the crop or scale tool to make it match. In Premiere, you can use the Effects Controls panel to scale a clip. In Final Cut, you can use the Crop tool in the Inspector. In DaVinci Resolve, you can use the Crop or Scale effect. Another technique is to use a very short transition (like a 1-frame dissolve or a wipe) to soften the cut. Sometimes just a tiny bit of motion blur or a slight zoom can make a cut less jarring. You can also use a technique called cutting on action or matching movement – for example, if the subject is moving, cut on the motion so that it looks like a continuous action. These small touches can significantly improve the overall look of your edit. Don’t overdo it – subtle is usually better. The audience should be focused on the story, not on the cuts.
Final Checks: As you refine the cut, regularly review the entire sequence to ensure the story still flows well. Check for any continuity issues: did you forget to include a reaction shot, or is there a jump cut that’s too noticeable? Make sure each scene transitions smoothly to the next. If you have a series of clips, check that the pacing between them is consistent. Sometimes adding a short B-roll or a cutaway can break up a long sequence of talking heads and keep the viewer engaged. Similarly, if a scene is too short, consider adding another take or a quick insert to give it more weight. Take breaks and come back to the edit with fresh eyes – you might catch something you missed earlier. The fine cut is about polishing the edit so that it’s tight, engaging, and free of any obvious flaws. When you’re satisfied, you’re ready to move on to the next step: color grading.
6. Color Grading
Color grading is the process of adjusting the colors, contrast, and overall look of your video to enhance its visual appeal and storytelling. It involves techniques like balancing exposure, correcting white balance, adjusting color saturation, and applying stylistic looks or LUTs. Here’s a recommended order for color grading and how to do it in each NLE:

Order of Operations: A typical workflow for color grading is to start with the primary adjustments and then move to secondary adjustments. Here’s the order:
Exposure/Contrast (Primary): First, adjust the overall brightness and contrast of the footage. In Premiere Pro, use the Lumetri panel’s Basic Correction section to adjust Exposure, Highlights, Shadows, Contrast, and Blacks. In Final Cut Pro, you can use the Color inspector to adjust Exposure, Contrast, and Gamma. In DaVinci Resolve, use the Color page’s Primary tab to adjust Exposure, Blacks, Highlights, and Gamma. The goal is to get a good base exposure and contrast – you want the video to have a balanced range of light and dark without clipping any important details. Adjust until the image looks natural but has some pop. Avoid going overboard at this stage; you can refine more in secondary corrections.
White Balance: Next, correct the white balance to ensure that the colors look accurate. In Premiere Pro, use the Color Temperature and Tint sliders in Lumetri Basic. In Final Cut Pro, use the White Balance tool in the Color inspector. In DaVinci Resolve, use the White Balance eyedropper tool in the Color page’s Primary tab. The idea is to make the whites look white and the blacks look black (or at least neutral). If your footage has a color cast (e.g. a green or orange tint), adjust the color temperature/tint until the image looks neutral. This step is crucial because it sets the baseline for all other color adjustments. If the white balance is off, everything else will look off too.
Saturation: After correcting exposure and white balance, you can adjust the overall color saturation. In Premiere Pro, use the Saturation slider in Lumetri Basic or the HSL Secondary panel for selective saturation. In Final Cut Pro, use the Saturation slider in the Color inspector or the Color panel’s Saturation control. In DaVinci Resolve, use the Saturation slider in the Color page’s Primary tab. You might increase or decrease saturation depending on the style you want. For example, if you’re going for a vibrant look, you might boost saturation slightly. If you want a more muted or cinematic look, you might reduce it. Be careful not to over-saturate to the point of unnatural colors. A good rule of thumb is to keep skin tones looking natural – avoid making people’s skin look orange or too red.
Look/LUT (Optional): At this point, you can apply a pre-made LUT (Look-Up Table) or a creative color grade. LUTs are preset color grades that can quickly change the look of your footage. In Premiere Pro, you can apply an LUT via the Lumetri panel’s Presets or Creative section. In Final Cut Pro, you can apply an LUT using the Color inspector’s 3D LUT effect. In DaVinci Resolve, you can apply an LUT by using the Color page’s Look node or by importing an LUT into the Looks folder. If you choose to use a LUT, apply it after the primary adjustments so that it doesn’t override your careful exposure and white balance work. Many editors like to use a camera-specific LUT as a starting point – for example, if you shot on a certain camera, you might use a LUT that mimics that camera’s film style. LUTs can be a great time-saver, but make sure they enhance the video rather than distract from it. If you prefer to grade manually, you can skip this step or use it for subtle enhancement.
Secondaries (Skin Tones, Sky, etc.): Finally, do any secondary color corrections to fine-tune specific elements. This might include adjusting skin tones, making the sky a certain color, or pulling out color from backgrounds. In Premiere Pro, use the HSL Secondary tool in Lumetri to select a color range (e.g. skin tones or blue skies) and adjust parameters like Hue, Saturation, and Luminance for that range. In Final Cut Pro, use the Color panel’s Color Wheels and Secondary controls to do the same. In DaVinci Resolve, use the Color Wheels and Secondary tools in the Color page – Resolve is particularly powerful here, allowing you to use nodes to apply multiple secondary corrections in layers. For example, you might create a node for skin tones, another for the sky, etc. When using secondary corrections, be precise: zoom in to ensure you’re not affecting areas you don’t want to. The goal is to enhance the video without creating unnatural or harsh looks. For instance, you might slightly warm up skin tones to make them look healthy, or slightly cool down the sky to make it more vibrant. These adjustments can make a big difference in the overall appearance of the video. Take your time with secondary corrections, as they can refine the look significantly.
Workflow Tips:
Use Presets or Templates: Keep a library of color presets or templates that you can apply to your footage. For example, you might have a preset for “Interview Warm” that adjusts skin tones and adds a slight warm look. In Premiere, you can save Lumetri presets; in Final Cut, you can save color adjustments as Favorites or use the Color Board to create custom looks. In DaVinci Resolve, you can save entire color grades as Power Grades and apply them across multiple clips or sequences. Having these presets can speed up your workflow, especially if you edit similar types of content often. For instance, if you frequently edit interviews, you might have a standard grade you apply to all interview footage to ensure consistency.
Save Camera Presets: As mentioned, it’s a good idea to create a color grade that’s tailored to each camera you use. Different cameras have different color characteristics, so a grade that works well for footage from Camera A might not work for Camera B. By creating a preset for each camera, you can import the footage and immediately apply the camera-specific grade, saving you 80% of the grading time. In Premiere, you can create a Lumetri preset for a particular camera. In Final Cut, you can create a Color Board or a Custom Look for that camera. In DaVinci Resolve, you can save a Power Grade for a camera. Then, when you import new footage from that camera, you just apply the preset and do minimal tweaks. This is a great efficiency hack.
Viewing Conditions: Remember to grade your video in a well-calibrated monitor environment. If you grade on a monitor that’s not properly calibrated, the colors might look different on other screens. Many editors use a reference monitor and keep the grading as neutral as possible, then use a LUT to apply a specific look for final output. It’s also important to preview your video on multiple devices (computer, TV, mobile) to ensure the colors translate well. You might find that your grade looks great on your calibrated monitor but a bit too saturated on a mobile device – adjustments can be made accordingly.
Stay Consistent: If you’re working on a project with multiple sequences or multiple videos that are related, try to maintain a consistent color style. This helps the audience recognize your work and also makes the videos feel like they belong together. For example, if you have a series of videos, use the same camera presets and similar secondary corrections for each. You can adjust per video for creative reasons, but a consistent overall look will make your content more professional.
DaVinci Resolve Color Page Advantage: DaVinci Resolve is often praised for its powerful color grading tools. It allows you to use nodes – think of them as layers of color adjustments – which can be very useful. For example, you might use one node for white balance, another for primary adjustments, another for a LUT, and another for skin tones. This non-destructive, node-based approach means you can easily tweak or remove any grade step without affecting others. It also allows you to create complex looks. If you’re comfortable with DaVinci Resolve’s color page, you can really fine-tune your video’s look. However, Premiere Pro and Final Cut Pro have improved their color tools a lot too. Premiere’s Lumetri and Final Cut’s Color panel both offer comprehensive controls. So, choose the tool you’re most comfortable with, but know that each has robust capabilities. If you’re a beginner, starting with Premiere or Final Cut might be easier due to their more straightforward interface for color correction, whereas DaVinci Resolve might offer more flexibility for advanced grading. The important thing is to get your video looking great and that the colors support the mood and message of the video.
7. Audio Mixing
Audio mixing is the process of balancing and enhancing the audio in your video to make it clear and engaging. This involves adjusting volume levels, applying effects like equalization and compression, and sometimes mixing multiple audio tracks together. Here’s a guide to audio mixing in your video:

Volume Levels and Mixing: Start by setting appropriate volume levels for all your audio tracks. This means ensuring that no single track is too loud or too quiet. A common rule of thumb is to keep the voiceover (VO) and dialogue relatively louder than background music or effects so that the audience can hear the dialogue clearly. However, you also don’t want the VO to be so loud that it overpowers the music. Use the gain or volume controls in your NLE to adjust levels. In Premiere Pro, you can use the Audio Track Mixer or the Effect Controls panel for individual clips. In Final Cut Pro, use the Audio Inspector to adjust volume. In DaVinci Resolve, use the Fairlight page’s audio mixer. Aim for a consistent volume across all clips. If some clips are noticeably quieter or louder than others, you might want to normalize them or adjust their gain. A good starting point is to get all audio tracks around -12 dB to -18 dB relative to each other, then use audio ducking (discussed below) to adjust specific instances.
Target Loudness: In addition to relative levels, it’s important to consider the loudness of the final mix. Different platforms have different loudness targets to ensure the audio is consistent. For example:
On YouTube, a typical target is around -14 LUFS (Loudness Units Full Scale). This is a standard for broadcast and online content to ensure your audio is neither too soft nor too loud.
For Shorts, Reels, or TikTok, you can aim for a slightly higher loudness – often around -12 to -10 LUFS – but be careful not to clip the audio (which would cause distortion). These platforms often have a lot of background noise and competition, so a bit higher loudness can help your video stand out, but always test to make sure it’s within acceptable limits.
For TV or Film, the target might be lower (around -23 LUFS) to avoid ear fatigue, but that’s outside the scope of this guide.

You can use a loudness meter in your NLE to monitor the overall loudness of your mix. In Premiere, you can enable the loudness meter in the Audio Track Mixer or use an external plugin. In Final Cut, you can use the Audio Level meter in the Inspector. In DaVinci Resolve, use the Fairlight page’s loudness meter. Aim to hit your target without clipping. If your mix is too loud, you might need to reduce the overall gain or apply a limiter. If it’s too soft, you might boost gain or use a compressor to make the quieter parts louder. The goal is to have a consistent, listenable volume.

Equalization (EQ): Apply equalization to adjust the frequency balance of your audio. A common practice is to high-pass filter voiceover and dialogue tracks to remove low-frequency rumble and noise. A high-pass filter around 80–100 Hz is often used – this will remove any low hums or rumbles from the microphone or room. Additionally, you might want to cut some mid-range frequencies (around 200–400 Hz) to reduce any “muddy” or boomy sound in the voice. You can do this by applying a notch filter or a slight cut in that range. In Premiere Pro, use the Parametric EQ effect. In Final Cut, use the Equalizer effect in the Audio Inspector. In DaVinci Resolve, use the Equalizer effect in the Fairlight page. EQ can greatly improve the clarity of your audio. For example, if your microphone has a lot of bass hiss, a high-pass filter will clean that up. If your voice sounds too nasal, a cut in the 500–1 kHz range might help. Experiment with EQ to find the sweet spot for each audio track. Remember that different voices and microphones might require different EQ settings, so be flexible.
Compression: Use compression to even out the volume levels. Compression will reduce the dynamic range of the audio – it will make loud parts quieter and soft parts louder, resulting in a more consistent volume. A common setup for voiceover is:
Threshold: Set this to around -12 dB to -18 dB, depending on how much you want to compress. You want it to start compressing when the volume gets fairly loud.
Ratio: A ratio of about 3:1 is often used for voice. This means that for every 3 dB above the threshold, the compressor will reduce the volume by 1 dB. A 3:1 ratio will give a moderate amount of compression, making the audio more consistent without making it sound too squashed.
Attack: Keep this relatively fast (around 10–20 ms) so that it starts compressing quickly when a loud sound hits.
Release: Keep this relatively fast too (around 100–200 ms) so that it releases quickly after the loud sound ends, to avoid any pumping or distortion.
Makeup Gain: After applying compression, you might need to add a bit of gain (often called “makeup gain”) to bring the overall volume back up to where it was. This ensures that the compressed audio isn’t quieter than the uncompressed audio. You can adjust the makeup gain in your NLE’s compressor effect.
Applying this kind of compression to your voiceover will make it sound more professional – the volume will be more consistent, and you won’t have to worry about the volume jumping around. You can use similar compression on other audio tracks too, like music, but you might use a different ratio (e.g. 4:1 or 5:1) for music to allow more dynamic range. In Premiere, use the Dynamic Link Compressor or the Audio Effect Rack to apply compression. In Final Cut, use the Compressor effect in the Audio Inspector. In DaVinci Resolve, use the Compressor effect in the Fairlight page. Start with the settings above and tweak them to your liking. Always listen to the result to make sure it sounds natural – over-compression can make audio sound flat and robotic, so use it judiciously.

Limiting: A limiter is similar to a compressor but more extreme. It’s used to prevent the audio from exceeding a certain level (the ceiling). For voiceover, a common limiter setting is:
Threshold: Set this just below the level you want to cap at. For example, if you want to cap at -1 dB, set the threshold around -2 dB.
Ratio: Typically a very high ratio (infinite, effectively) so that once the audio hits the threshold, it’s limited. In practice, you might set it to something like 20:1.
Attack and Release: Usually set very fast (e.g. 10 ms attack, 50 ms release) so that it responds immediately and quickly releases.
Ceiling: Set the ceiling to your target level (e.g. -1 dB). This is the maximum volume the limiter will allow.
Applying a limiter ensures that your audio doesn’t clip or get too loud. In Premiere, use the Limiter effect. In Final Cut, use the Limiter effect. In DaVinci Resolve, use the Limiter effect in Fairlight. For voiceover, a limiter can be very helpful because it prevents accidental spikes in volume from blowing out the audio. It’s especially useful if you’re recording voiceover in a less controlled environment. Just be careful not to over-limit – a little bit of limiting is good, but too much will flatten the audio. A rule of thumb is to use the limiter to protect the audio, not to make it sound worse.

Audio Ducking: Audio ducking is a technique where one audio track automatically lowers in volume when another track plays. This is commonly used to make voiceover or dialogue audible over background music. For example, if you have a music track playing in the background and a voiceover talking over it, you might want the music to duck (get quieter) during the voiceover and come back up when the voiceover ends. In your NLE, you can set up audio ducking in a couple of ways:
Manual Ducking: You can manually adjust the volume of the music track down when the voiceover starts and up when it ends. This can be done by placing keyframes on the music track’s volume envelope at the appropriate times. It works, but it’s a bit tedious and not very precise.
Auto-Ducking: Many modern NLEs support auto-ducking. In Premiere Pro, you can use the Dynamic Link Compressor to set up an auto-ducking effect. In the Compressor settings, you can specify a “ducking track” – the track that will duck. Then, when the ducking track’s volume goes above a certain threshold, the target track (like the music) will automatically lower in volume. In Final Cut Pro, you can use the Audio Mixer to create an Automation curve for ducking. In DaVinci Resolve, you can use the Fairlight page’s audio mixer to create a ducking effect by having the voiceover track control the music track’s volume. Essentially, you create a track in Fairlight that sends a control signal to the music track’s volume.
Auto-ducking is very useful because it ensures the voiceover is always clear without you having to manually adjust every time. For YouTube, you might set the voiceover to duck the music by about 10–14 dB when it’s speaking. For social media (Shorts, etc.), you might not need as much ducking since the video is shorter and the music might be more background. Experiment with the amount of ducking to find what works best. Just remember that the goal is to make the voiceover audible, not to completely eliminate the music. You want the music to still be present but lower enough that the dialogue is the focus. Audio ducking can greatly improve the listenability of your video, so take advantage of it.

Noise Reduction (if needed): If your audio has background noise (like hum, hiss, or room noise), you can apply noise reduction. In Premiere Pro, use the Noise Reduction/Restoration effect. In Final Cut, use the Noise Reduction effect in the Audio Inspector. In DaVinci Resolve, use the Noise Reduction effect in Fairlight. This is especially useful if you recorded audio in a less than ideal environment. Noise reduction can significantly improve the quality of your audio, but it can also remove some of the clarity, so use it sparingly. A common approach is to apply a small amount of noise reduction and then manually tweak it to preserve as much of the voice as possible. If the noise is very bad, you might consider re-recording the audio or using additional techniques like adding a noise gate (which mutes audio below a certain threshold) to reduce background noise.
Final Checks: After applying all your audio adjustments, play through the entire video and listen carefully. Check for any clipping or distortion – if you see a red light in your NLE’s audio meter, that means the audio is clipping and you need to reduce the gain or adjust your limiter. Check that the voiceover is clear and not drowned out by music. Check that the music and sound effects are balanced and not too loud. Also, listen for any unnatural sounds – for example, if you used a lot of compression, does the audio sound too “processed”? Adjust as needed. It’s a good idea to export a short preview of the audio mix and play it on different speakers or headphones to make sure it sounds good. Sometimes what sounds good on your computer might not sound good on a phone or a TV. If you have any issues, make the necessary fixes. A well-mixed audio track can greatly enhance the viewing experience, so don’t skip this step.
8. Graphics/Titles
Adding graphics and titles to your video can enhance the storytelling and make it more professional. This includes things like lower thirds (text that appears at the bottom of the screen), on-screen text, logos, and any animated graphics. Here’s how to handle graphics and titles in your workflow:

Reusable Templates: Create a library of reusable graphics and title templates. In Premiere Pro, use the Essential Graphics panel. In Final Cut Pro, use the Titles panel. In DaVinci Resolve, use the Fusion page or the Titles panel. Having templates for things like lower thirds, end screens, and logos means you can drag them into your timeline and customize them quickly. For example, if you create a lower third template, you can just drag it into the timeline, replace the text, and it will automatically have the correct formatting and animation. This saves you time and ensures consistency across your videos. You can even save entire templates (with placeholders) so that every new project can start with the same set of graphics ready to go.
Lower Thirds: Lower thirds are a common type of graphic – they typically appear at the bottom of the screen and display a name, title, or short text related to the speaker or subject. When designing lower thirds, keep them simple and easy to read. Aim for left-aligned text (the name or title on the left, the subtitle on the right, for example) and limit it to 2 lines of text at most. This ensures it doesn’t take up too much screen space and is legible. Use a clean, sans-serif font that’s easy to read from a distance. Consider the background color or shape of the lower third – a solid color block behind the text can help it stand out against the video. Make sure the text color contrasts well with the background. For example, if the background is black, use white text; if it’s a light color, use dark text. You can also add a subtle drop shadow or outline to the text to make it more visible. If you’re using a template, make sure to customize the text (name, title, etc.) for each speaker. Many editors like to use a lower third that’s consistent in style but can be easily swapped out for different names. Keep in mind that the lower third should appear and disappear at the right moments – you don’t want it covering important action or lasting too long. Typically, you’ll show the lower third when the person is speaking and hide it when they’re not. You can do this by cutting the lower third on and off the timeline or by using keyframes to fade it in and out.
End Screen / Outro: The end screen is a graphic that appears at the end of your video, often showing options for the viewer (like subscribing, watching related videos, etc.). If you’re creating a YouTube video, you might include YouTube end cards as well. Design your end screen to be 5 seconds long (or more if needed for text). Make sure to leave room for any interactive elements (YouTube end cards are usually 120×120 pixels, so plan accordingly). The end screen should be simple and not distract from the content. Use a solid color background or a subtle pattern. Display a few options with text or icons. For example, you might have a “Subscribe” button graphic, a “Watch Next” graphic linking to another video, and a “Follow on Social” graphic. If you’re using a template, just replace the text and links. Keep the text short and easy to read. The end screen should be visible enough that the viewer can see it, but not so flashy that it overpowers the video. It’s a good idea to use a different style for the end screen than the rest of the video (maybe a darker background or a different font) to signify that it’s the end. After designing the end screen, make sure to place it at the very end of the timeline, just before the credits or the final fade out.
Logos and Overlays: If you have a logo or any other graphic overlay, place it in a corner of the screen (often the top right or top left). Keep it small enough that it doesn’t cover important content but large enough to be visible. If you have multiple logos (for example, a company logo and a sponsor logo), make sure they are appropriately sized and placed so they don’t overlap. You might use a template for logo placement too. Some editors use a corner bug or a watermark for their personal branding. If so, keep it consistent in style (maybe always in the top right corner with a slight transparency) so it becomes recognizable. If you’re using a transparent PNG for your logo, you can adjust its opacity in the timeline so it doesn’t cover the video content. Also, consider adding a short fade-in at the beginning of the video and a fade-out at the end for the logo, so it doesn’t pop on or off suddenly. This can give a more polished look.
Animation and Effects: For some graphics, you might want to add animation – for example, a lower third that slides in from the bottom or a title that fades in. In Premiere Pro, you can use the Essential Graphics panel to create motion graphics. In Final Cut Pro, use the Titles panel to add motion effects. In DaVinci Resolve, use the Fusion page to create custom animations. Animation can be very effective in grabbing attention, but don’t overdo it. Keep it simple and relevant. A common animation is a fade or a slide – these are subtle and won’t distract from the content. If you’re using a template, it might already have animations built in. Make sure to test any animations to ensure they look good and don’t cause any issues (like text not aligning properly or graphics covering other elements). It’s also a good idea to save your animated graphics as templates so you can reuse them in other projects.
Placeholders and Updates: When creating a video, especially if you’re working with a client or a team, it’s common to use placeholders for certain elements. For example, you might have a placeholder for the client’s logo or a placeholder text for a future subtitle. Make sure to note these placeholders and update them before finalizing the video. Don’t forget to add any necessary credits or disclaimers as well – for example, if you’re using licensed music, include the copyright notice. Place these in a text graphic at the end of the video or as overlays if needed. If you have a template for credits, just replace the names and details.
Consistency: As with color grading, try to maintain a consistent look for your graphics. Use the same fonts, color schemes, and styles across all your videos if possible. This creates a cohesive brand identity. If you’re part of a team, make sure everyone is using the same template library and style guide. Consistency in graphics will make your videos look more professional and polished.
9. Review / Feedback Loop
Once you’ve completed your edit, it’s important to get feedback from others (clients, producers, team members) and incorporate those changes. This feedback loop ensures that the final video meets the expectations and needs of the stakeholders. Here’s how to handle the review and feedback process:

Versioning Your Exports: Create different versions of your video as you incorporate feedback. A common versioning scheme is:
v01 (Initial Edit): The first export of your rough cut or assembly. Send this to reviewers for feedback.
v02 (Feedback Applied): After incorporating the first round of feedback, export this version.
v03-feedback, v04-lock, etc.: Continue incrementing as needed with each round of feedback and final lock.
Use clear filenames so it’s easy to tell which version is which. For example: PROJECTNAME_edit_v01.mp4, PROJECTNAME_edit_v02.mp4, etc. This prevents confusion about which version was approved. It’s also a good practice to store all review exports in a dedicated folder, such as 04_EXPORTS/REVIEW, as mentioned in the project setup. This keeps your final exports separate from your review files and ensures you always know where to find the latest version for feedback.

Frame-Accurate Comments: When sharing your video for review, use frame-accurate feedback tools if possible. This means being able to pinpoint the exact frame or timecode where a change is needed. There are several ways to do this:
Frame.io: Frame.io is a popular platform for video reviews. You can upload your video to Frame.io, and reviewers can leave comments with timestamps. Frame.io will even highlight the frame that the comment refers to. This is very efficient because it’s easy to see exactly what needs to be changed.
Dropbox Replay: Dropbox also has a feature called Dropbox Replay where you can share a video and reviewers can leave comments with timestamps. It’s a bit simpler than Frame.io but still effective.
YouTube Unlisted Link: If you don’t have access to specialized tools, you can always share a link to an unlisted YouTube video. While not as interactive as Frame.io, reviewers can watch the video and leave comments in the YouTube comments section or via email. You can then note the timestamp and make the necessary changes. Just be aware that YouTube comments can be hard to track, so you might want to ask reviewers to mention the timestamp in their comments.
Screen Annotation Software: Another option is to use screen annotation software. For example, you could share your video on a screen sharing session and use a tool like Microsoft Whiteboard or Adobe Spark to mark up the video. While this works, it’s not as efficient as using a purpose-built review tool.
Using frame-accurate feedback is crucial because it minimizes miscommunication. If someone says, “Cut out that long pause at 0:15,” you know exactly where to go. Without frame accuracy, you might waste time searching for the specific part. By leveraging these tools, you can streamline the feedback process and make it as efficient as possible.

Collaboration and Revisions: Once you receive feedback, carefully review each comment and decide how to implement it. Sometimes a change is straightforward (e.g. “Remove the extra 5 seconds at the end”), and other times it might be more complex (e.g. “Add a new scene between 0:30 and 0:45”). Update your project accordingly. If the feedback involves cutting or adding footage, you’ll need to make those changes in your timeline. If it involves changing a graphic or text, update the corresponding clip or title. Always make sure to save a new version of your project when you make changes (for example, if you were working on v01, save as v02 before making changes). This way, you can always go back if something goes wrong or if you need to revert. After making the changes, export a new version of the video and send it back for the next round of feedback. Repeat this process until you’ve addressed all feedback and the client or team is satisfied with the final version.
Final Lock and Approval: Once you’ve incorporated all feedback and the video is as you and the stakeholders want it, it’s time to lock the project. This means no more changes will be made to the timeline or media. Before locking, double-check everything: make sure all graphics are correct, all text is spelled correctly, the audio levels are consistent, and the video quality is as expected. It’s a good idea to do a final quality check on different devices to ensure the video looks good everywhere. Once everything is locked, save the project with a final version name (e.g. PROJECTNAME_final_v04). You can also export a high-resolution copy at this point (in case you need to provide a master file). Keep the project file saved in a safe place, and consider backing it up if necessary. At this stage, you’re ready to deliver the final video to the client or for publishing.
10. Export Settings (Platform)
After you’ve completed your edit and received final approval, it’s time to export the video. Different platforms (YouTube, social media, etc.) have different recommended export settings to ensure the video looks good and plays correctly. Here are some guidelines for common platforms:

YouTube: For YouTube, you’ll typically export in H.264 format (the most common video format for online video). YouTube supports a variety of resolutions and frame rates, but a common choice is 1080p at 30 fps for standard videos. If you want to upload in 4K, you can choose 4K at 24 or 30 fps. Use the High Profile setting for better compression efficiency. For encoding, use a VBR 2-pass encoding method. VBR (Variable Bitrate) allows the encoder to use more bits for complex scenes and fewer bits for simple scenes, resulting in a better quality-to-file-size ratio. 2-pass encoding means the encoder will analyze the video twice – first to gather data, then to encode – which results in a more accurate bitrate distribution. For audio, use AAC at a bitrate of 320 kbps. AAC is a high-quality audio codec and 320 kbps ensures the audio is crisp and clear. Make sure to set the container (file format) to .mp4. YouTube also supports other formats, but MP4 is widely compatible. You can use the preset for “YouTube 1080p” in your NLE if available, or manually set these parameters. It’s worth noting that YouTube’s compression can be quite good, so even if you export with a bitrate of around 8–12 Mbps for 1080p, it should look decent on YouTube. However, if you want to preserve the highest quality, you might export at a higher bitrate. Just be aware that a higher bitrate means a larger file size.
Social Media Shorts/Reels/TikTok: Platforms like Instagram Reels, TikTok, and YouTube Shorts typically have vertical video dimensions (e.g. 1080×1920 pixels). When exporting for these, use the same frame rate as the original (usually 30 or 60 fps). For resolution, stick to 1080p (since the maximum for these is 1080p on TikTok, and 1080p on Instagram Reels). The bitrate can be a bit higher than YouTube because these platforms often compress less. A bitrate of 8–12 Mbps is generally fine for 1080p at 30/60 fps. Again, use H.264, High Profile, VBR 2-pass encoding. The audio should be AAC at 320 kbps. Since these videos are short, you might even consider a slightly higher bitrate (like 15 Mbps) to ensure they look sharp. Just keep in mind that TikTok and Reels have a maximum file size of around 28–50 MB for 60 seconds, so a very high bitrate might result in a file too large to upload. If you run into that, you may need to reduce the bitrate. It’s a good idea to test uploading a short clip with different bitrates to see what works. One more thing: make sure to export with the correct aspect ratio (9:16). Some NLEs allow you to create a sequence in 9:16 for these, which is ideal. Also, ensure that the video is square if required for TikTok (some older TikTok videos are square). Always check the platform’s guidelines for specific requirements, but the above settings should cover most cases.
Other Platforms: For other platforms like Vimeo, Facebook, or Twitter, the settings are generally similar to YouTube or social media. Vimeo often recommends H.264 with similar settings. Facebook and Twitter also accept H.264 MP4s. Just make sure the aspect ratio is correct for the platform (16:9 for Facebook, 9:16 for Instagram, etc.). If you’re exporting for a specific device (like a mobile app or a website), you might need to adjust the resolution or frame rate accordingly. But in most cases, the guidelines above will work. It’s also worth mentioning that some platforms (like YouTube) support higher frame rates for smoother motion (60 fps or 120 fps). If you shot at a high frame rate and want to export in slow motion, you can do that by exporting at a lower frame rate and letting YouTube or the platform handle the slow motion. Just make sure to inform the platform that it’s a high frame rate source so it can optimize playback.
Export Presets: To make exporting easier, consider creating export presets in your NLE for each common platform. For example, you can create a preset for “YouTube 1080p” with the settings we discussed, and a preset for “TikTok 1080×1920 30fps”. Then, whenever you need to export, you can just select the appropriate preset. This saves you from having to manually set the same parameters each time. Most NLEs allow you to save export settings as presets. In Premiere Pro, you can use the Export Settings dialog and save your settings as a preset. In Final Cut Pro, you can use the Share menu to create a custom export preset. In DaVinci Resolve, you can use the Deliver page to create a preset. By using presets, you ensure consistency and avoid mistakes (like forgetting to set the correct bitrate). It’s a small step that can save a lot of time and ensure your videos are optimized for each platform.
Check Export Quality: After exporting, always watch a few seconds of the exported video to make sure everything looks correct. Check for any artifacts or compression issues. If you notice something, you might need to adjust the export settings (e.g. increase the bitrate if there’s too much compression, or decrease it if the file size is too large). Also, check the audio to ensure it’s still clear and there are no glitches. If you exported in H.264, sometimes the audio might have a slight delay – you can fix this by exporting with a different container or by adjusting the audio offset. These are edge cases, but it’s good to be aware. Overall, by following the recommended settings for each platform, you’ll ensure that your video looks great and plays smoothly for your audience.
Keyboard Shortcuts Starter Pack
To work efficiently, it’s helpful to learn and use keyboard shortcuts in your editing software. Here’s a starter pack of useful shortcuts (many of these are similar across NLEs, though the keybindings might differ slightly):

Ripple Trim: In Premiere Pro, use Q to trim the start of a clip and W to trim the end of a clip. In Final Cut Pro, use the ripple trim tool (or press Shift+] to trim the end or Shift+[ to trim the start). In DaVinci Resolve Cut page, you can use the Ripple trim tool (or press Shift+T). Ripple trims adjust a clip’s length and automatically adjust the surrounding edits (rippling the timeline) so that nothing is left hanging. This is great for fine-tuning the length of a clip without affecting the flow of the rest of the edit.
Add Edit: In Premiere, press Ctrl+K (Windows) or Command+K (Mac) to split a clip at the playhead. In Final Cut, press B to split a clip at the playhead. In DaVinci Resolve, press B to split a clip at the playhead. Adding an edit is the basic way to cut a clip into two pieces – use this when you want to remove a section of a clip.
Insert Edit: In Premiere, press , (comma) to insert a clip at the playhead position without overwriting. In Final Cut, you can use the insert edit tool (or press B to enter the insert tool). In DaVinci Resolve Cut page, you can use the Insert tool (or Shift+I). Insert edits add clips without removing existing content, which is useful for building a sequence without cutting out existing material accidentally.
Overwrite Edit: In Premiere, press . (period) to overwrite existing content at the playhead. In Final Cut, use the overwrite tool (or press O). In DaVinci Resolve Cut page, use the Overwrite tool (or Shift+O). Overwrite edits replace whatever is at the playhead with the selected clip. Use these when you’re ready to cut out the old material and replace it with the new.
Zoom to Fit: In Premiere, press \ (backslash) to zoom the timeline to fit the entire sequence. In Final Cut, press Command+0 to zoom to fit. In DaVinci Resolve, press 0 to zoom to fit. This is handy when you want to see the whole timeline at once or when you want to zoom in on a specific area.
Marker: In Premiere, press M to place a marker at the playhead. In Final Cut, press Command+M to place a marker. In DaVinci Resolve, press M to place a marker. Markers are useful for quickly navigating and noting important points in your timeline.
Toggle Proxies: If you’re using proxies, map a key to toggle between original and proxy media. In Premiere, you can use a custom shortcut (e.g. Ctrl+Shift+P). In Final Cut, you might use a similar shortcut. In DaVinci Resolve, you can use the Proxy button in the Media Pool (or in the Playback tab) to toggle between Original and Proxy. Being able to quickly switch between proxies and originals can save time, especially when you need to verify something in high resolution.
Export Frame: Create a custom shortcut to export the current frame as an image. In Premiere, you can use Shift+E (or any other key combination you set). In Final Cut, you can use the File > Export > Frame command, but setting a keyboard shortcut is useful. In DaVinci Resolve, you can use the File > Export > Image command and set a shortcut. Exporting a frame can be helpful for grabbing a still image or checking a frame of the video.
Workspace Shortcuts: Many NLEs allow you to switch between workspaces or arrange panels. For example, in Premiere, you can use Ctrl+1, Ctrl+2, etc., to switch between default workspaces. In Final Cut, you can use Command+1, Command+2, etc., to switch to different views (Browser, Timeline, etc.). In DaVinci Resolve, you can use the Tab key to switch between the Media, Edit, Color, Fairlight, and Deliver pages. These shortcuts can help you quickly navigate the software and focus on the task at hand (editing, grading, audio mixing, etc.).
Play/Pause: In all NLEs, Spacebar is typically the play/pause key. In Premiere, pressing Spacebar plays the timeline from the current position; pressing it again pauses. In Final Cut, Spacebar does the same. In DaVinci Resolve, pressing Spacebar plays the timeline. This is the most basic but essential shortcut – it allows you to preview your edit in real-time.
Learning these shortcuts can significantly speed up your workflow. It might take some time to memorize them, but with practice, you’ll find that you can edit much faster using the keyboard than reaching for the mouse. Many editors also customize their keyboard shortcuts to match their workflow (for example, if you prefer a certain key for a specific function). If you have a preferred layout, you can export your keyboard shortcuts and use them on different machines or share them with your team. The key is to use whatever setup makes you the most efficient. With a good set of keyboard shortcuts, you’ll be able to edit more quickly and with fewer mistakes, which is invaluable as you work on more complex projects.

Automation / Time Savers
To further streamline your editing process, consider using automation and time-saving features in your NLE. Here are some tips:

Blank Project Templates: Create a “blank project” file that already has your bin structure, sequences, and even some initial settings. This can be a template for all your future projects. For example, you can create a project in Premiere with all the bins we discussed, a sequence set to 1080p 29.97, and even some markers or placeholders. Then, whenever you start a new project, you can simply duplicate this blank project file. This way, you don’t have to rebuild your bins and sequences from scratch every time – you can start editing immediately. It might take a bit of time to set up the initial template, but it will save you 15–20 minutes per project, which adds up over time. In Final Cut Pro, you can use the File > New > Project from Template feature to create templates. In DaVinci Resolve, you can use the New Project option and save it as a template. Having a template ready means you can focus on editing rather than organizing your project structure.
Watch Folders: Premiere Pro has a feature called Watch Folders that can automate media ingestion and processing. A watch folder is a folder that Premiere monitors for new files. When you import media into the watch folder, Premiere will automatically import those files into your project. This is great if you receive media on a regular basis (like daily shoots or a client sending footage). You can also use watch folders to automate tasks like proxy generation. For example, you can set up a watch folder for your raw media that automatically generates proxies in the 03_PROXIES folder whenever new media is added. This means you don’t have to manually right-click and create proxies for each clip – Premiere does it for you. Watch folders can also be used for exporting – you could have a watch folder that automatically exports media whenever a certain condition is met (though that’s less common). To set up a watch folder in Premiere, go to File > Automate to Sequence > Watch Folder. You can specify the source folder and the destination sequence. This is a powerful automation tool that can save you a lot of time, especially if you work with a lot of media.
DaVinci Resolve PowerGrades and Adjustment Clips: DaVinci Resolve’s PowerGrade feature allows you to save an entire color grade as a preset. You can then apply this PowerGrade to multiple clips or even entire sequences. This is useful if you have a consistent look you want to apply to a series of videos or if you want to quickly apply a color grade to all your footage. In addition, DaVinci Resolve has Adjustment Clips – these are clips that affect all the clips below them in the timeline. You can use an adjustment clip to apply a global effect (like a color grade, noise reduction, or stabilization) to an entire section of your timeline without having to apply the effect to each clip individually. For example, you could create an adjustment clip at the beginning of your timeline, apply a color grade to it, and that grade will apply to all subsequent clips until you add another adjustment clip. This is a huge time-saver for applying global effects. You can also use adjustment clips to apply transitions or motion effects to a range of clips at once. In Premiere Pro, you can achieve something similar with Adjustment Layers, and in Final Cut Pro, you can use Compound Clips or Apply to All effects. The key is to use these features to automate repetitive tasks and apply effects to multiple clips at once, rather than doing them clip by clip.
Batch Rename: Before importing media into your project, consider using a batch renaming tool to rename your files in a consistent format. For example, if you have a lot of clips from a shoot with filenames like IMG_1234.MOV, IMG_1235.MOV, etc., you can batch rename them to something like CAM_A_001, CAM_A_002, etc. This makes it easier to organize them in your project and to reference them by name. Most operating systems have a batch rename feature (Windows has “Rename multiple files” and macOS has “Rename Finder Items”). You can also use third-party software or scripting to do batch renaming. The goal is to have all your media files named in a way that’s human-readable and easy to sort. This might not save you time during editing, but it will save you time during project setup and media organization, which is part of the overall workflow.
Automated Workflows with Scripts/Plugins: For more advanced users, you can use scripting or plugins to automate tasks. For example, you could write a script that automatically applies a series of effects to all your clips or that automatically generates a title for each speaker in an interview. While this is beyond the scope of a basic guide, it’s worth noting that many NLEs have APIs or scripting languages (like Premiere’s ExtendScript, Final Cut’s AppleScript, or DaVinci Resolve’s Python scripting) that can be used to create custom automation. If you find yourself doing the same thing over and over, it might be worth exploring if there’s a way to automate it. This could significantly speed up your workflow for complex projects.
Collaboration / Cloud
Finally, in today’s collaborative editing environment, it’s important to consider how you’ll work with others and how to manage your project in the cloud. Here are some tips:

Shared Drive: Keep your media and project files on a shared drive or cloud storage. This way, multiple editors or team members can access the files simultaneously. Options include Dropbox, Google Drive, OneDrive, or a dedicated shared network drive. Make sure everyone has read/write access and that the file paths are consistent. For example, you might have a folder structure on Dropbox like /Projects/PROJECTNAME/02_MEDIA, /Projects/PROJECTNAME/01_PROJECT, etc. Each editor can then map that to a local drive letter or just access it via the cloud. Using a shared drive means that if one person makes changes to the media or the project file, others can see those changes in real-time. This is great for collaboration. Just be aware of potential conflicts – if two people try to edit the same project file at the same time, it can cause issues. To mitigate this, consider using a version control system or at least make sure everyone saves their work frequently and merges changes carefully.
Project File in Cloud: You can also store your project file (the .prproj, .fcpbundle, or .drp file) in the cloud. This way, you can open it from different locations. For example, you might start editing on your desktop at home, then continue on your laptop at the office, and then share it with a client. Storing the project file in the cloud ensures it’s always accessible. However, be cautious: not all NLEs handle cloud project files well. Some might require the media to be local, and some might not handle concurrent edits on the same project file. In Premiere Pro, if you store the project file in Dropbox, Premiere might have trouble finding the media if it’s stored elsewhere. So, a common approach is to store the media on the shared drive and the project file on the cloud, but ensure that the media paths in the project file are relative or that everyone’s local drive maps to the same path. Alternatively, you can use cloud-based NLE solutions, but those are beyond the scope of this guide. The key is to manage your project file and media in a way that supports collaboration.
Local Media Paths: When working with a shared drive, make sure each editor has local media paths that match the template. For example, your project might be set up with media paths like C:\PROJECTS\PROJECTNAME\02_MEDIA\CAM_A. If you’re using a shared drive, you might map that to Z:\02_MEDIA\CAM_A on each editor’s machine. To do this, you can use Media Cache Locations in Premiere or Media Manager in Final Cut to reassign the media paths. If everyone has the same drive letter or path structure, Premiere and Final Cut will be able to find the media without issues. DaVinci Resolve is a bit more flexible – it allows you to use a Media Storage path that can be a network path, so you can keep the media on a server and Resolve will find it. This means you can keep the project file in the cloud and still use DaVinci Resolve, because the media is on the server. If you’re using a cloud storage service that doesn’t have local drive mappings, you might need to download the media to each machine or use an online editor. Regardless, the goal is that each editor can access the media and project file easily, so they can work on the project without manual file management.
DaVinci Resolve Shared Libraries: If you’re using DaVinci Resolve and you have multiple editors or a team, you can take advantage of Shared Libraries. In DaVinci Resolve, a shared library allows multiple editors to work on the same project at the same time, with changes synced in real-time. This is very powerful for collaboration. You can store the project library on a network drive, and all editors can open it. They can each have their own timeline or work on the same timeline – DaVinci Resolve will handle the syncing. This is similar to how a cloud-based NLE works, but it’s built into DaVinci Resolve. If you’re a serious editor working with a team, this can save a lot of time in coordination. However, setting up shared libraries requires a bit of configuration (like setting up a shared folder and ensuring everyone has access). It’s also important to note that only certain features are available in shared libraries – for example, you can’t have two people edit the same clip at the same time, but you can work on different parts of the timeline. If you’re not ready for a full shared library, you can still use the DRP file method: one editor works on the project, exports the DRP file, and shares it with others. The others then open the DRP file and relink the media (since they might have the media in a different location). This is a common workflow and it works well for smaller teams or when you don’t need real-time collaboration.
Frame.io or Other Cloud Review Platforms: In addition to using the cloud for media and project files, consider using cloud-based review platforms for feedback. As mentioned earlier, Frame.io is a great tool for getting feedback because it allows reviewers to see the video and leave comments with timestamps. You can upload your final video to Frame.io and invite your clients or team to review it. They can watch the video, pause it, and click to leave a comment at any time. Frame.io will then send you an email notification when there are new comments, and you can see exactly where each comment is. This streamlines the feedback process and keeps all communication in one place. Other platforms like Wipster, Dropbox Replay, or even just YouTube with comments can be used, but Frame.io is widely used in the industry for a reason – it’s very user-friendly and integrates well with editing workflows. By using such platforms, you can get feedback from anywhere in the world, and you can track the progress of changes easily. It’s an important part of the collaboration process, especially if you’re working remotely or with multiple stakeholders.
Backup and Version Control: Finally, remember to back up your project files regularly and use version control for your edits. This is especially important if you’re collaborating. You can use cloud storage to automatically back up your project file each time you save it (many cloud services have version history features). You should also maintain a separate backup of your project file and media in case something goes wrong. Version control for your edits can be as simple as keeping different versions of your project file (e.g. PROJECTNAME_v01.prproj, PROJECTNAME_v02.prproj, etc.) and storing them in a version control system or just on an external drive. If you ever need to revert to a previous version, you’ll have it. For example, if a reviewer asks for a change that you later decide you don’t like, you can revert to the previous version. This kind of backup and version control is crucial in any editing workflow, but it’s even more important when working with others. It ensures that you can always recover from mistakes and that you can easily communicate with your team about what changes have been made.
By implementing these collaboration and cloud tips, you can work more efficiently with others and ensure that your project is always accessible and up-to-date. Whether you’re working with a team in the same office or remotely, these practices will help you manage your project effectively and reduce the risk of losing work or causing conflicts. Good collaboration and cloud management are as important as the editing itself in a modern video production workflow.
